# OOP Calculator

A simple desktop calculator written in Python with an object-oriented design and a Tkinter graphical interface.

## Features

- Addition, subtraction, multiplication, and division
- Power using `^`
- Remainder using `%`
- Clear button (`C`)

## Run

Requires Python 3. Run from a terminal:

```bash
python calculator.py
```

Tkinter is included with most standard Python installations. On some Linux distributions, install the `python3-tk` package if it is missing.
